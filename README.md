# Study Analytics

A Python-based study tracking and analytics application for recording study sessions and analyzing study habits.

## About

Study Analytics allows users to record their study sessions and view statistics about their studying. The project is being developed as a hands-on way to learn Python while building a useful application.

This project is inspired by a previous version I built in Java and will eventually include more advanced data analysis and visualization features.

## Planned Features

* [ ] Add study sessions
* [ ] View all study sessions
* [ ] Calculate total study time
* [ ] Calculate average scores
* [ ] Analyze study time by subject
* [ ] Track study streaks
* [ ] Save and load study data
* [ ] Search and filter study sessions
* [ ] Create data visualizations
* [ ] Analyze study habits and patterns
